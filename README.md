This project forecasts monthly U.S. residential electricity sales. The goal is an interactive live forecast of that demand.

## Features
- An interactive plot of the raw series, with sliders to adjust the training, holdout, and forecast horizon in months
- An STL Decomposition displaying the components of the time series and plot of the seasonal subseries, showing the trend for every month throughout the years.
- A table displaying the Fitted Model Specifications
- A plot showing the model accuracies of the forecasts against held-out validation actuals, measured in millions of kWh, along with a table for the training and validation accuracy for the models, sorted by RMSE
- A residual diagnostics section which includes an ACF residual plot of the three models as well as a residual-time plot, with Ljung-Box test results.
- A forecast plot with an adjustable forecast window and 80% prediction intervals applied to the forecasts generated by each model. 

## Dataset

Residential sales to ultimate customers, from the EIA Monthly Energy Review, Table 7.6 (series ESRCPUS). Values are million kilowatthours. The series is monthly, January 1973 through July 2026.

Source: [EIA Monthly Energy Review, Table 7.6](https://www.eia.gov/totalenergy/data/browser/?tbl=T07.06)

A copy of the monthly residential series is in `data/residential_electricity.csv`.

| Column | Description |
| --- | --- |
| `date` | First day of the month |
| `residential_million_kwh` | Residential electricity sales, million kWh |
